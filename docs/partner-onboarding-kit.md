# Partner onboarding kit

Status: **kit checklist** (P1). The live `/partners` page already captures enquiries (`partner_enquiry` analytics). This document defines the pack to send after a qualified partner conversation.

## Partner types
1. **Referral** — introducers (lawyers, CSPs, advisors) who send managers/SPV leads  
2. **Joint go-to-market** — co-marketing with complementary vendors  
3. **Integrations** — technical partners (banking, custody, CRM)

## Onboarding steps (after enquiry)
1. Qualify type (referral / joint / integration)  
2. Send this kit + calendar link  
3. Agree attribution (UTM / referral code)  
4. Optional: add partner logo to TrustedBy with written approval  
5. Quarterly pipeline sync
